# Every key

`Ctrl` can be `Cmd` wherever your terminal sends it.

## Everywhere

| Key | Does |
|---|---|
| `Esc` | the menu — or first, closes a note or scene beside, or lets go of a selection |
| `F1` | this help, on the topic for where you are |
| `?` | this help too, wherever you aren't typing; on the page it's a question mark |
| `Ctrl-K` | find anything: actions, scenes, notes, themes |
| `Tab` | the next pane; `Shift-Tab` the one before |
| `Ctrl-S` | save now (autosave already does) |
| `Ctrl-Q` | quit, saving everything first |
| `Ctrl-Z` | undo: typing in the page; a delete, rename, move or new item in the outline |
| `Ctrl-Y` | redo |
| `Ctrl-F` | find in the scene; again for the whole book |
| `Ctrl-D` | focus mode |
| `Ctrl-T` | every note and TK in the book |
| `Ctrl-O` | the note for the name at the cursor |
| `Alt-↑` | move the selected scene up; `Alt-↓` down |
| `F2` | start or pause the timer |
| `F3` | reset the timer |
| `F4` | previous track |
| `F5` | play or pause |
| `F6` | next track |
| `F7` | the music player |
| `F8` | spelling suggestions |
| `F9` | themes |

## The outline

| Key | Does |
|---|---|
| `↑` `↓` | move; `j` `k` too |
| `→` | unfold, or open a scene; `l` too |
| `←` | fold, or go up a level; `h` too |
| `Enter` | fold or unfold, or open a scene; `Space` too |
| `n` | new scene |
| `c` | new chapter |
| `p` | new part |
| `N` | new folder |
| `r` | rename |
| `d` | delete, to the Trash |
| `K` | move up; `J` down |
| `H` | the scene's history |
| `b` | the corkboard |
| `v` | show the scene beside |
| `/` | find in the whole book |
| `t` | themes |
| `q` | quit |

## The page

| Key | Does |
|---|---|
| `Home` | start of the line; `End` the end |
| `PgUp` | a screenful up; `PgDn` down |
| `Ctrl-C` | copy the selection |
| `Ctrl-X` | cut the selection |
| `Ctrl-Shift-Z` | redo, where the terminal can send it |

Click to place the cursor, drag to select, and click or right-click an underlined word for its spellings.

## The find bar

| Key | Does |
|---|---|
| `Enter` | the next match (`↓` too); `↑` the one before |
| `Ctrl-R` | replace every match |
| `Ctrl-W` | whole words or inside words (`Alt-W` too) |
| `Ctrl-E` | exact case or any case (`Alt-C` too) |

`Tab` moves between the find and replace boxes.

## The Pomodoro pane

| Key | Does |
|---|---|
| `Enter` | start or pause; `Space` too |
| `r` | reset |
| `←` `→` | Pomodoro or Visualizer; `h` `l` too |

## The music pane

| Key | Does |
|---|---|
| `[` `]` | previous and next track |
| `←` `→` | ten seconds back and forward |
| `Space` | play or pause |
| `r` | repeat |
| `s` | shuffle |
| `+` `-` | volume |
| `l` | like |
| `Enter` | the player |

## A note or scene beside

| Key | Does |
|---|---|
| `↑` `↓` | scenes the name appears in, or scroll |
| `Enter` | go to that scene, or write in the one beside |
| `o` | open the note, or write in the scene beside |
| `q` | close it; `Esc` too |

## Help

| Key | Does |
|---|---|
| `↑` `↓` | choose a topic; in an article, scroll a line (`j` `k` too) |
| `Enter` | read it; `→` and `Tab` too |
| `PgDn` | scroll the article; `PgUp`, `Home` and `End` too, and `Space` inside it |
| `←` | back to the topics; `h` too |
| `F1` | close the help |

Type to search every topic. `Esc` clears the search, then closes the help. In a narrow window the article has the whole box, and `Esc` steps back from it to the topics first.
