# The notebook & names

The notebook is the book's sections for things that aren't the story: **Characters**, **Places**, **Notes** and **Research**. Each note is a Markdown file, like a scene.

## Names light up

The title of every note in the notebook is a **name**: as you write, names appear in the accent colour. A note can have other names too, with `aliases:` in its frontmatter:

`aliases: [Kae, the Ferryman]`

## Opening a name's note

Put the cursor on a name and press `Ctrl-O` (*Open the note for the name under the cursor*, in `Ctrl-K`). Its note opens **beside** the scene, with **Appears in**: every scene that mentions it.

- `Tab` moves into the note. `↑` `↓` choose a scene from *Appears in* and `Enter` goes there.
- `o` opens the note itself to edit it.
- `PgDn` or `Space` scrolls.
- `Esc` (or `Ctrl-O` again) puts the note away.

## Names that drift

*Check names for near-miss spellings* in `Ctrl-K` finds spellings one or two letters away from a name in your notebook — "Kaelan" where the note says "Kaelen" — with where each one is.

- `Enter` goes to the first place it's used.
- `f` fixes it everywhere in the manuscript at once.

Your notebook's names also teach the spellchecker, so they're never underlined.
